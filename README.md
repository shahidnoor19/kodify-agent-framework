# Kodify Agent Framework

A production-grade AI Support Copilot, built step by step in the Kodify Dev YouTube course
"Microsoft Agent Framework in .NET".

## Tech stack

- .NET 10, ASP.NET Core MVC
- Microsoft Agent Framework
- Microsoft Foundry
- Azure AI Search
- EF Core + .NET Aspire

## Episodes

1. Intro, live demo and architecture
2. Setup: .NET 10, VS Code Insiders, Microsoft Foundry
3. Your first agent and the layers
4. Streaming, sessions and structured output
5. Models and cost
6. Testing from day one
